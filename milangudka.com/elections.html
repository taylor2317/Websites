Local Elections Results Tracker

During the 2026 UK Local Elections, I received many complaints from friends and family that result tracking websites were too confusing to understand, with all sorts of information scattered across the pages. In order to fix this issue, I created a tracker website to allow users to easily view the results of the elections in a clear and concise manner, in a site that strives to simplify the user experience and minisise information as much as possible. This project involved using web scraping techniques to gather data from credible sources. I then used this data to create a user-friendly interface that allowed users to easily navigate through the results and view them in a visually appealing way. The website also included features such as recent changes to enhance the user experience. Overall, this project was a great opportunity for me to apply my web development skills and create a useful tool for those interested in following the UK Local Elections.
